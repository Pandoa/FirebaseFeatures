Frequently Asked Questions

How fast does Remote Config update parameters inside the game client?

Parameters fetch via standard asynchronous calls. Once cached, they apply immediately on application boot or mid-session without restarting the game executable.

Is Firestore reliable enough to handle secure player inventories?

Yes. Inventory operations are executed through Firestore Transactions. This guarantees atomic read-and-write cycles on the database cluster, preventing data race conditions or item duplication bugs.

Can I use the Realtime Database to power a matchmaking lobby?

Yes. Realtime Database maintains low-latency duplex connections. Combined with value-changed listeners, it can track active lobby slots, group formations, and client readiness states.

How does offline persistence operate if a player loses connection?

The local SDK caches write mutations to disk. The client fires success callbacks locally, and the plugin flushes the pending transaction queue sequentially once internet connection handshakes resume.

Can I run targeted live-events for specific player segments?

Yes. By mapping Firebase Analytics user properties to Remote Config criteria, you can adjust balance values, localized text string sets, or economy variables for specific regions or level brackets.

How secure is player data against client-side memory editing?

Completely secure when using Firebase Security Rules. You write server-side logic matching the requesting client's Auth token directly against their allocated data path to block unauthorized edits.
